# 데이터·권리·AI 전송 원칙

## 참조 이미지와 창작물

참조 이미지, 미공개 캐릭터 설정, 생성 결과는 사용자 자산이다. 합성 fixture만 Git과 테스트에 넣는다. 원본·스크린샷·프롬프트를 디버깅 편의로 커밋하거나 외부에 공개하지 않는다. 사용자에게 업로드할 권리가 있는지 확인할 수 있게 하며, 그 확인을 법적 권리 보증으로 표시하지 않는다.

파일은 확장자만 신뢰하지 않고 크기·실제 형식·디코딩 한도를 검사한다. EXIF 등 필요 없는 메타데이터는 공급자 전송과 내보내기 전에 제거할 정책을 정한다. 구체적인 용량/픽셀 제한은 구현 계획에서 결정한다.

## 외부 AI 경계

생성 기능은 명시적인 사용자 동작에서 실행한다. 전송할 바이블·참조 이미지·수정 이미지, 공급자, 예상 비용과 취소 한계를 보여준다. 관련 없는 프로젝트 데이터는 보내지 않는다. 공급자의 저장·학습 이용·삭제 조건은 도입 시 공식 문서로 확인하고 출처 등록부에 남긴다.

모델이 분석한 특징·생성된 문구는 제안 데이터다. 그 안의 지시문으로 권한·도구 실행·파일 접근 범위를 확대하지 않는다. 공급자 결과를 자동 공개·자동 제출하지 않는다. 비용 상한과 재시도 한도를 마련한다.

## 저장과 로그

비밀키는 저장소·클라이언트 코드·문서·로그에서 제외한다. signed URL, 원본 경로, 전체 이미지/base64, 프롬프트 원문을 기본 로그에 남기지 않는다. 작업 ID·모델·상태·오류 코드·측정된 사용량 위주로 기록한다.

로컬/서버 저장, 인증, 소유권 검사, 보존 기간, 백업과 삭제 전파는 미확정이다. 서버 저장을 도입하면 프로젝트·자산·다운로드 권한을 소유자 기준으로 검사하고, 삭제·탈퇴 시 파생 자산과 미완료 job 처리도 설계한다. 구현되지 않은 삭제 보장을 UI에 표시하지 않는다.

## 범위 제한

추적·광고·결제·공개 갤러리·자동 카카오 제출은 현재 범위 밖이다. 카카오의 생성형 AI 제작물 정책은 미확인으로 기록한다. 규격 검사만으로 제출 가능성이나 저작권 문제 없음을 단정하지 않는다.

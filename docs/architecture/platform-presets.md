# 플랫폼 규격 프리셋 계약

## 근거 상태

공식 정지 이미지 구성·제작 안내에서 32개·360×360 PNG·150 KB 이하, 아이콘 1개·78×78 PNG·16 KB 이하, 투명 배경 및 대표 이미지 선택을 확인했다. [확인 기록](../references/kakao-static-evidence.md)에 위치와 적용 한계를 남겼다. 제안/상품화 단계별 필수 범위·KB 환산·파일명·AI 정책은 추가 확인한다.

`KAKAO_STATIC`, `KAKAO_ANIMATED`, `KAKAO_LARGE`는 설계용 식별자이며 실행 가능한 검증 프리셋은 아직 없다. 기획의 icon.png 같은 이름은 앱 예시다. 움직임 수치나 알려지지 않은 규칙을 추정하여 확정하지 않는다.

## 버전에 필요한 필드

| 필드                    | 의미                                                         |
| ----------------------- | ------------------------------------------------------------ |
| id / version            | 프리셋 식별자와 불변 버전                                    |
| platform / type / stage | 플랫폼, 정지/움직임/큰 유형, 제안/상품화 단계                |
| evidence_status         | draft / verified / needs_recheck / retired                   |
| sources / checked_at    | 원문 URL·절/제목·짧은 근거 또는 의역, 확인 날짜              |
| rules                   | 룰별 식별자, 적용 대상, 값·단위, 필수/권장, 출처             |
| file_groups             | 본 이미지·샘플·대표 이미지 등 그룹별 수량·형식               |
| naming / packaging      | 파일명·순서·추가 파일 규칙, 플랫폼 규칙인지 앱 관례인지 표시 |

확인되지 않은 필수 값은 null/unknown으로 남긴다. 생략한 조건과 제한이 없는 조건은 구분한다. 서로 다른 제안·상품화 규칙을 합쳐 하나의 “카카오 규격”으로 만들지 않는다. 큰 이모티콘 등의 여러 허용 크기는 단일 폭·높이로 뭉개지 않는다.

## 검사 결과

- pass: 확인된 규칙에 대해 실제 파일이 조건을 만족한다.
- fail: 확인된 필수 규칙을 위반한다. 항목 ID·측정값·기준을 표시한다.
- unknown: 규칙 출처나 값을 모르거나 해당 검사가 아직 구현되지 않았다.
- warning: 공식 권장 사항 또는 앱 품질 안내다. 필수 위반과 구분한다.

프리셋이 verified이고 모든 필수 규칙이 pass여야 해당 버전의 파일 검사 통과로 표시한다. needs_recheck·unknown·미선택 항목이 있으면 카카오용 통과 표시는 차단한다. 사용자 지정 ZIP은 별도 목적의 작업물이며 공식 규격 적합 표시를 붙이지 않는다.

## 구현 시 반드시 검증할 것

- 확장자 대신 실제 디코딩한 포맷·폭·높이·색/투명도 정보, 실제 바이트 길이를 사용한다.
- PNG가 알파 정보를 담을 수 있다는 사실만으로 배경이 제거됐다고 판단하지 않는다. 투명도 처리와 시각적 배경 검토 범위를 명시한다.
- 개수·중복 순서·선택 누락·파일명 충돌을 세트 단위로 확인한다.
- 용량의 KB 해석과 경계 포함 여부는 출처로 확정하고 바이트 단위 경계값 테스트를 둔다.
- 출력 파일명에서 경로 이동 문자를 허용하지 않는다. ZIP에 대상 폴더 밖 경로·원본 경로를 넣지 않는다.
- 아이콘 등 추가 파일은 출처가 요구할 때만 필수 검사로 둔다. 앱 자체 manifest는 공식 제출 ZIP 밖의 보고서로 기본 제공한다.
- 움직임 규칙은 MVP 3에서 실제 지원 포맷·프레임·타이밍·루프 기준을 확인한 후 추가한다.

## 규격 변경 절차

공식 본문 확인 → 룰별 근거 기록 → 새 프리셋 버전 → 경계값 QA → 별도 리뷰 → 활성화. 이전 프로젝트는 기존 버전을 유지한다. 새 버전 적용 시 재검사하고 이전 보고서를 stale로 표시한다. 출처가 바뀌었거나 재확인이 필요한 경우 verified를 그대로 신뢰하지 않는다.

[공식 출처 등록부](../references/official-sources.md)를 갱신한다. 파일 규격 충족은 저작권 판단·AI 제작물 허용·플랫폼 승인 보장이 아니다.

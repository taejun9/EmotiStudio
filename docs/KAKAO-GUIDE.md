# 카카오 수량 기준과 애니메이션 범위

확인일: 2026-09-30. 카카오 공식 고객센터에서 연결한 작가 안내서를 브라우저로 직접 확인했습니다.

| 구분              | 공식 이모티콘 수량 | 이미지 규격                                               |
| ----------------- | ------------------ | --------------------------------------------------------- |
| 멈춰있는 이모티콘 | 32개               | 투명 PNG, 360×360px, 150KB 이하                           |
| 움직이는 이모티콘 | 24개               | 투명 WebP, 360×360px, 650KB 이하, 최대 24프레임, 4회 반복 |

두 유형 모두 78×78px·16KB 이하 PNG 아이콘 1개가 별도로 필요합니다. 움직이는 이모티콘 제안 시에는 24개 중 최소 3개를 움직이는 WebP로 제출하고 나머지는 PNG로 제출할 수 있습니다. 현재 공식 안내는 과거의 ‘GIF 3개’ 안내와 다릅니다.

## 이 앱에 반영한 내용

- 새 프로젝트 목표 수량은 정지 32개 / 움직이는 24개입니다. 클라이언트가 다른 수량을 보내도 서버가 거부합니다.
- 기존 작업은 원래 세트 수량과 결과물을 보존합니다. 최초 늘보군 체험 프로젝트는 6개로 유지됩니다.
- 움직이는 세트는 캐릭터 프리셋 또는 AI가 동작별 자세 8개를 그린 시트를 사용합니다. 선택한 부위 밖은 생성된 첫 프레임을 유지하며 연속 프레임으로 인코딩합니다. 한 장의 그림 전체에 회전·확대·이동을 주는 생성 기능은 제거했습니다. 이전 결과물과 버전은 보존합니다.
- 실제 다중 프레임 WebP와 GIF, 정지 PNG, 검수용 프레임 시트를 저장합니다. 출력은 360×360px·최대 24프레임의 일반 미리보기용 무한 반복입니다. 인코더는 같은 프레임을 합칠 수 있고 실제 프레임 수를 기록합니다. GIF는 256색 및 이진 투명도 제한이 있으므로 부드러운 반투명 경계에는 WebP가 적합합니다.
- 검수 화면에서 재생·정지, 프레임별 이동, 동작과 영역 수정, 버전 비교·복원, 전체 승인 후 ZIP 다운로드를 지원합니다. 실제 AI 동작 수정은 새로운 프레임을 생성하므로 이미지 API 사용량에 포함됩니다.
- 새 캐릭터 프리셋은 늘보군·토끼찬구 각각 정지 32종과 움직이는 24종의 서로 다른 자세·표정·소품을 사용합니다. 코드로 작성한 일러스트와 부위별 동작이며, 임의 입력을 해석한 AI 생성과 구분해 표시합니다. 기존 6장/손 인사 예제 기록은 보존합니다.

## 제출 적합성과 구분

수량을 맞춘 일반 이미지 패키지이며 카카오 제출 적합성을 인증하는 기능은 아닙니다. 이 앱의 ZIP에는 별도 상품 아이콘이 없고, 개별 파일 용량의 카카오 상한이나 4회 반복 설정을 강제하지 않습니다. 공식 가이드는 WebP를 카카오 전용 WebP Animator로 제작하도록 안내합니다.

또한 현재 카카오 운영 원칙은 **생성형 AI를 활용해 제작한 이모티콘의 제안을 제한**합니다. 이 앱에서 만든 AI 이미지와 이전에 AI로 제작한 늘보군 예제 이미지를 ‘바로 카카오에 판매할 수 있는 결과물’로 안내하지 않습니다. 제안 전 최신 운영 원칙과 유형별 가이드를 확인해야 합니다.

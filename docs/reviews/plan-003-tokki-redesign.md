# plan-003-tokki-redesign Review

## Summary

최신 토끼찬구 설정화의 흰 몸, 곧은 분홍 귀, 분홍 볼, 분홍 백팩과 당근 키링을 프리셋·대표 이미지·32개 정지·24개 부위 동작에 반영했다. 기존 저장 작업과 늘보군 출력은 보존했다. 구현에 참여하지 않은 `quality_review` 에이전트가 읽기 전용으로 코드와 실제 출력물을 독립 검토했고 최종 수정 필수 지적은 0건이다.

## QA

- `npm ci`, `python3 harness/scripts/verify_base.py --implementation`, `npm run verify`, `git diff --check` 통과.
- 최종 Python10 + Git정책13 + 앱/API/미디어50 + 브라우저10 = 83개 통과. 형식·타입·production 빌드 통과.
- 아트 수정 후 전체 실행 중 기존 보안 요청이 157초 무응답으로 해당 테스트 프로세스를 종료한 실행은 실패로 기록했다. 소스 변경 없이 보안7개 분리 검사(2.48초), 최종 전체 재실행(앱52.2초/E2E45.0초)이 통과했다.
- 실제 격리 API로 정지32/동작24개를 생성·완료·ZIP 내보내기하고 파일 크기·투명도·360px·ZIP 무결성을 확인했다.
- 늘보군32PNG/24프레임시트 SHA-256과 기존 tokki.png 바이트가 변경 전후 동일하다.
- 리뷰어는 정지32장 전체와 동작24개/192프레임, 120~160px 밝음·어둠 가독성, 수정된3동작의360px프레임, GIF/WebP 실제 디코딩 결과를 확인했다. 전체 자동검사 성공은 총괄의 도구 결과를 전달받아 확인했다.

## Findings

- P2 해결: 우산 기둥이 몸 뒤에 가려져 천만 떠 보였다. 토끼 전용 우산축을 얼굴 바깥으로 옮겨 오른손에 연결하고 재검수했다.
- P2 해결: 검수 모음GIF의 균일250ms가 실제 출력의 프레임 지연과 달랐다. 실제 timeline을 사용하고 인코딩 후 일치 검사를 추가했다. 8프레임/무한반복/지연 `[430,170,170,230,360,120,120,400]`ms를 실제 디코딩으로 확인했다.
- 품질 개선: 커피 컵과 양손이 입까지 움직이고, 양손이 키보드를 번갈아 누르며, 기다림에서 손목시계를 들어 확인한다. 일부 반복되던 표정을 분리했다. 추가 잘림·소품 이탈·큰 루프 점프는 발견하지 못했다.
- 새 대표 URL은 명시 allowlist로 제한한다. 프리셋을 선택한 경우에만 참조를 저장하고 null 제거 의사를 유지한다. 이전 컨셉/세트/이미지를 일괄 변경하는 경로는 없다.

## Residual Risk

작은 채팅에서 사용할 수 있는 깔끔한 코드 기반 프리셋으로 판단한다. 일부 표정과 부위 동작은 공통 구조를 사용하며 모든 장면이 풍부한 전신 연기를 갖춘 것은 아니다. 작은 키링·꽃다발 세부는 120px에서 생략되어 보인다. 손그림 질감의 재현, 실제 유료 AI 결과 품질, 카카오 심사·판매 승인과 시장 반응은 검증하지 않았다.

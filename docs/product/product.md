# EmotiStudio 제품 정의

개인 이모티콘 작가와 캐릭터 IP 보유자가 컨셉을 저장하고 여러 이모티콘 세트를 제작·검수하는 한국어 웹 스튜디오다. 현재 React/Vite·Express·SQLite 앱이 구현되어 있다. 실행 가능한 범위는 [README](../../README.md)와 [API 계약](../API-CONTRACT.md)을 기준으로 한다.

## 현재 제공하는 흐름

컨셉 저장 → 같은 캐릭터의 정지·움직이는 세트 생성 → 방향성 선택·직접 작성 → 생성 → 개별 검수·수정·대사 편집 → 완료·ZIP 다운로드.

| 영역          | 현재 기능                                                     | 경계                                                 |
| ------------- | ------------------------------------------------------------- | ---------------------------------------------------- |
| 컨셉·세트     | 캐릭터 이름·설명·성격·대상·참조, 부모 컨셉에서 여러 세트 생성 | 버전별 Character Bible이나 다중 참조 관리와는 다름   |
| 기획          | 규칙 기반 방향성 제안과 사용자 직접 작성                      | 외부 텍스트 모델 기반 기획은 아님                    |
| 생성          | 코드 기반 늘보군·토끼찬구 프리셋, 서버 OpenAI 이미지 생성     | 무료 프리셋은 자유 컨셉·피드백을 AI로 해석하지 않음  |
| 검수·수정     | 항목 승인·수정 요청, 개별 재생성, 버전 비교·복원              | 범용 복수 후보 선택과 부모 후보 계보는 후속 설계     |
| 움직임·대사   | 프레임 검수·동작 수정, 한글 대사 켜기·끄기·편집               | 부드러운 연결이나 캐릭터 동일성을 보장하지 않음      |
| 저장·계정     | SQLite·파일 저장, 게스트와 등록 계정, 소유권 검사             | 메일 인증·비밀번호 재설정 메일·협업 공유는 미구현    |
| 완료·내보내기 | 목표 수량과 승인 확인, PNG/WebP/GIF ZIP와 manifest            | 전체 플랫폼 제출 규격 검사나 심사 승인을 뜻하지 않음 |

새 세트 목표는 정지 32개·움직이는 24개이며 기존 작업은 저장된 수량을 보존한다. 적용 범위와 근거는 [카카오 가이드 확인 기록](../KAKAO-GUIDE.md)을 따른다. 실제 AI 생성은 등록 계정·서버 키·사용량 한도가 필요하고 비용이 발생한다. 무료 프리셋과 대사 합성은 이미지 API를 호출하지 않는다.

## 유지할 제품 원칙

1. 하나의 캐릭터 컨셉을 여러 주제의 세트에 재사용한다. 부모 변경으로 기존 세트를 몰래 덮어쓰지 않는다.
2. 생성 방식과 한계를 드러낸다. 코드 프리셋을 자유 컨셉을 해석한 AI 결과로 표시하지 않는다.
3. 수정 결과와 과거 버전을 보존하고, 바뀐 이미지의 검수 승인을 다시 받는다.
4. 대사 없는 원본과 표시·내보내기 결과를 구분한다.
5. 파일 검사, 캐릭터 일관성 판단, 사용자 승인, 플랫폼 심사 승인을 구분한다.

## 원래 기획에서 남은 확장

버전별 Character Bible·구조화된 외형 DNA, 다중 참조의 master/우선순위·권리 확인, 명시적인 후보 계보와 입력 스냅샷, 출처가 있는 플랫폼 프리셋과 독립 검사 보고서는 아직 구현 목표다. 규격 검사기는 룰별 `pass/fail/unknown`과 변경 시 재검사, 검사 파일과 ZIP 파일의 일치를 제공해야 한다.

원래 MVP 단계는 순차 완료 표시가 아니다. 움직이는 결과의 일부 기능은 이미 제공하지만, 정지 제작 MVP의 바이블·전체 규격 검사 요구는 남아 있다. 후속으로 Reference Lock, 검증된 일관성 평가와 사용자 승인 기반 수정, 추가 플랫폼, 협업·버전 관리 UI를 검토한다. [백로그](roadmap.md)와 [도메인 설계](../architecture/domain-model.md)에 이를 구분한다.

일관성 점수의 검증 방법이 정해지기 전에는 97% 같은 수치를 정확도로 표시하지 않는다. 카카오 직접 제출·자동 계정 조작·결제·광고·추적은 현재 범위가 아니다. AI 제작물 정책, 단계별 규격과 용량 환산 등 외부 정책의 공백은 [공식 출처](../references/official-sources.md)에서 확인하고 제품 보장으로 바꾸지 않는다.

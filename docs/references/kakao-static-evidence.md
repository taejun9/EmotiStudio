# 카카오 정지 이미지 가이드 확인 기록

출처: [카카오 공식 작가 안내서 — 멈춰있는 이모티콘](https://kakaoemoticonstudio.notion.site/emoticon). 확인일: 2026-09-30. 공식 스튜디오 홈페이지가 연결한 Notion 안내서의 유형별 이미지 가이드에서 브라우저 본문을 확인했다.

## 확인한 내용

| 원문 위치                    | 확인한 조건                                                 | 설계에 반영할 방식                                   |
| ---------------------------- | ----------------------------------------------------------- | ---------------------------------------------------- |
| 구성 표 / 1. 이모티콘 이미지 | 32개, PNG, 360×360 px, 각각 150 KB 이하                     | 본 이미지 그룹 규칙의 근거                           |
| 1. 이모티콘 이미지 주의사항  | 투명 배경, 어두운 배경에서 문구가 보이도록 흰색 외곽선 안내 | 파일 투명도 검사와 시각적 가독성 검토를 분리         |
| 2. 아이콘 이미지             | 1개, PNG, 78×78 px, 16 KB 이하                              | 아이콘 자산 규칙의 근거                              |
| 필수 이미지 가이드 도입부    | 72dpi 및 RGB 제작 안내                                      | 실제 파일 메타데이터와 강제/권장 판정 방식 추가 확인 |
| 3. 대표 이미지               | 이모티콘 이미지 가운데 하나 선택                            | 별도 신규 이미지 파일로 자동 계산하지 않음           |

짧은 원문 근거: “이미지의 배경은 투명으로 제작해 주세요.”

## 아직 확정하지 않을 것

본문은 상품 구성과 제작을 설명한다. 모든 파일이 최초 제안 시점에도 필수인지, 상품화 단계와 어떻게 나뉘는지는 추가 확인한다. 150 KB와 16 KB를 각각 어떤 바이트 수로 계산하는지도 이 페이지에 명시된 근거가 없어 미확정이다. 파일명, ZIP 수납 방식, 아이콘 배경의 세부 조건 역시 별도로 확인한다.

이 표는 읽은 내용의 근거 기록이다. 실행 가능한 verified 프리셋은 아직 없다. 미확인 필수 규칙을 unknown으로 두고, 단계별 범위와 바이트 경계값을 확정한 뒤 프리셋 구현·QA·리뷰를 거쳐 활성화한다. 생성형 AI 제작물의 허용 여부는 이 이미지 가이드로 판단하지 않는다.

## User Request

새로 제공한 토끼찬구 설정화를 기준으로 캐릭터 컨셉과 정지·움직이는 결과물을 다시 제작하고, 실제 채팅 이모티콘으로 쓸 때의 시각 품질과 기능을 검사한다.

## Goal

곧게 선 긴 귀와 분홍 귀 안쪽, 둥근 분홍 볼, 활발한 눈썹·입, 흰 몸과 분홍 백팩·당근 키링을 일관되게 반영한다. 정지 32종과 부위 동작 24종을 다시 렌더링하고, 중복·잘림·작은 화면 가독성·부위 연결·대사·개별 수정·저장·내보내기를 확인한다. 자동 파일 검사와 시각적 판단을 구분해 결과와 남은 한계를 제시한다.

## Non-Goals

전체 Character Bible/플랫폼 검사기, 카카오 자동 제출, 결제, 실제 유료 AI 배치 호출은 포함하지 않는다. 다른 사용자의 기존 DB 이미지와 승인 상태를 자동 덮어쓰지 않는다.

## Completion Notes

구현·최종 QA·독립 리뷰를 완료했다. 토끼찬구 32개 정지와 24개 부위 동작을 실제 API로 다시 제작했고, 각 개별 결과·대사 없는 정지 원본·밝음/어둠 모음·실제 PNG/WebP/GIF ZIP·검사 JSON·HTML을 Git에서 제외된 기본 작업 공간의 `test-results/tokki-v2-preview/`에 보존했다. `npm run preview:tokki`로 재현 가능하다.

우산 손잡이와 미리보기 타이밍 지적은 수정 후 재검수했다. 시각 평가는 실제 채팅에서 사용할 수 있는 깔끔한 프리셋이며, 모든 장면의 풍부한 독립 연기·유료 AI 실출력·카카오 판매 승인을 입증하지 않는다. 앞선 보안 소켓 무응답 실행은 성공 수에 포함하지 않았고 같은 소스의 분리7개 및 전체83개 재실행 성공을 기록했다.

이 완료 기록은 구현·QA·리뷰 범위다. 커밋·push·PR 검사·main 통합·로컬 동기화·관리 worktree 정리는 이어지는 통합 단계에서 수행하고 PR과 최종 보고로 실제 결과를 남긴다. 보호 규칙 우회나 main 직접 push를 하지 않는다.
